# **TRAICE** Documentation

TRAICE (**T**racking **R**ealtime **AI** **C**arbon **E**missions) is free MIT-licensed interactive visualization software designed for real-time monitoring
of AI systems carbon emissions.

# Getting Started

TRAICE provides comprehensive insights into carbon footprint data and federated learning algorithm efficiency, enabling users to track environmental impact and model effectiveness simultaneously.

## Technical Documentation

TRAICE consists of three main components: a **Server**, a **Client** and a **Python Library**. This document provides technical documentation for each of these components.

## Installation Guide

The **Installation Guide** will help you install the application, setup the server and the library. It also provides a brief review of the system and highlights key elements for its deployment.

## User Manual

The **User Manual** will provide guidance in the use of the client. It explains the main features of the application, and contains a walkthrough of the interfaces.
